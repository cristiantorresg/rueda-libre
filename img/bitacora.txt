Roles
-HTML:Es el que estructura la pagina web.

Ejemplo: Puede designar el espacio donde se va a mostrar una imagen como un banner
en la pagina, en el archivo html deja el espacio listo y sube la imagen como tal.

-CSS:Es el encargado de hacer que la pagina web cumpla con una estetica visual
atractiva para el cliente.

Ejemplo: Mediante CSS le da estilo al banner, configurando colores y a la imagen del banner le da un suavizado en las esquinas con un Border-radius

-JavaScript:Quien se encargará de que el html y css tengan elementos interactivos.

Ejemplo: El banner tendra un efecto que al pasar el mouse sobre el, va a hacer
zoom.
